Student attendance register format for tuition classes

A simple student attendance register format for tuition and coaching classes: the columns to use, the P / A / L codes, and the formula that works out each student's attendance percentage.

Columns in a monthly attendance register

  • Student ID and name, one row per student.
  • Batch, if you run more than one.
  • One column per day of the month (1 to 31).
  • Totals: days present, days absent and attendance percentage.

Codes to use

P = present, A = absent, L = leave informed in advance. Leave a cell blank on days with no class, so holidays do not count against anyone.

Sample register

IDStudent12345PresentAbsentAttendance %
S001Aarav SharmaPPAPP4180%
S002Diya IyerPPPPP50100%
S003Kabir ReddyAPAPL2250%

Sample data. Attendance % counts only P and A days; L days are left out.

Attendance percentage formula (Excel or Google Sheets)

If a student's marks are in cells D6 to AH6:

=COUNTIF(D6:AH6,"P")/(COUNTIF(D6:AH6,"P")+COUNTIF(D6:AH6,"A"))

Format the cell as a percentage. Many centres talk to parents when attendance falls below 75%.
